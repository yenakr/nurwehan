# NUR위한 | 한양대학교 간호대학 OPEN LAB 신청 시스템

한양대학교 간호대학 학생들을 위한 실습실(OPEN LAB) 신청 및 학과 공지사항 확인을 위한 웹 시스템입니다.

## 주요 기능
- **OPEN LAB 신청**: 실습실 사용 일시 및 필요한 기자재 예약
- **공지사항 확인**: 학과 주요 소식 및 공지 확인
- **신청 내역 관리**: 본인의 실습실 신청 내역 확인 및 관리

## 기술 스택
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (CSS Variables)

## 시작하기

먼저, 의존성 패키지를 설치합니다:

```bash
npm install
```

개발 서버를 실행합니다:

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 결과를 확인하세요.
